# Kill Streak Gold

Плагин для ExileCore (ExileAPI, PoE1): серии убийств, счётчики убийств по редкости монстров
(обычные / магические / редкие / уникальные) и золото за локацию и за сессию — в одной
компактной панели на экране.

> English documentation: [README.md](README.md)

## Возможности

- **Kill streak** — текущая серия, лучшая за сессию и за локацию, настраиваемое окно
  между убийствами (по умолчанию 5 секунд)
- **Полоска-таймер** — сколько осталось до разрыва серии
- **Убийства по редкости** — Normal / Magic / Rare / Unique отдельно для локации и сессии
- **Золото** — получено в текущей локации и за сессию + золото/час; траты не засчитываются
- **История локаций** — последние зачищенные локации с убийствами и золотом
- **Уведомление** о убийстве уникального монстра (отключается)
- **Кнопка сброса сессии** в настройках
- Гибкая настройка: позиция панели, цвета по редкости, видимость секций, окно стрика

## Как считается

Убийство фиксируется, когда враждебный монстр, которого плагин видел живым, становится
мёртвым. Скрытые и не заспавненные монстры игнорируются. Статистика локации сбрасывается
при смене зоны, сессионная — кнопкой в настройках. Золото считается по приросту общего
баланса, поэтому траты никогда не увеличивают счётчик.

## Установка

1. Скопируйте папку `KillStreakGold` в `Plugins\Source\` вашего ExileCore:

   ```
   Plugins
   |
   ->Source
     |
     ->KillStreakGold
       ->KillStreakGold.csproj
       ->KillStreakGold.cs
       ->KillStreakGoldSettings.cs
   ```

2. Запустите HUD — плагин скомпилируется автоматически.
3. Откройте меню (F12), найдите **Kill Streak Gold** и включите его.

## Сборка вручную (для разработки)

```
dotnet build KillStreakGold.csproj -p:exapiPackage=C:\Path\To\Your\PoeHelper
```

`exapiPackage` — путь к папке с `ExileCore.dll` (или переменная окружения для IDE).
